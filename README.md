# GEArts Portfolio

An interactive web portfolio showcasing curated art appreciation assignments, creative explorations, and collections.

## 🚀 Live Demo
View the live site here: [GEArts Portfolio on GitHub Pages](https://belleYza.github.io/GeArts-Portfolio/)

## ✨ Features
- **Responsive Layout:** Optimized for mobile and desktop screens using Tailwind CSS.
- **Scroll-Spy Navigation:** Dynamic pill-style active section highlights.
- **Interactive Collections:** Dynamic filtering for origami and art appreciation submissions.

## 🛠️ Built With
- HTML5
- Tailwind CSS
- JavaScript (ES6+)
